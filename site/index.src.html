Compose documents.
Ship one file.

rr expands a small file of <rr-*> tags into a polished, self-contained HTML page — specs, reports, briefs, decks. No framework, no bundler, no network requests.

report.rr.html

<rr-section id="tldr" title="TL;DR" icon="bolt">
  <rr-tiles>
    <rr-tile label="Shipped" value="3" icon="check" caption="this week"/>
  </rr-tiles>
  <rr-callout tone="amber"><b>Open decision.</b> TTL: 5 or 15 min.</rr-callout>
  <rr-progress label="Rollout" pct="80" n="8/10 regions"/>
</rr-section>

rr build report.rr.html emits report.html — CSS, JS, and icons inlined, tree-shaken to what the page uses. It opens from disk and travels as an attachment. See a full document.

The problem

Quick documents cost an afternoon

A spec, report, or debrief either looks like raw markdown or costs hours of hand-written CSS.

Hand-written HTML drifts

Ask an agent for an HTML document and it invents a new design every time — boilerplate that drifts, for a lot of tokens.

Builds don't travel

Anything with a bundler or a CDN can't be emailed, committed, or opened from disk without setup.

The fix

A small vocabulary

Thirty-odd tags — cards, callouts, checklists, annotatable code exhibits, flip cards, reader-paced decks. Compose out of proven pieces instead of designing from scratch.

Correct by construction

Unknown tag, missing prop, bad icon name — the build stops and names the fix. A composed document can't quietly rot.

One file out

Everything the page uses is inlined; everything it doesn't is left out. The output makes zero network requests.

Your design system, not ours

No bundled look by default

rr ships structural CSS and a neutral token contract — nothing more. Redefine the tokens and every component wears your brand. Want the bundled look instead? Pass --theme rr.

brand.css

:root {
  --bg: #0a0a0a; --surface: #141414; --line: #262626;
  --fg: #ededed; --muted: #a1a1a1; --accent: #ff5d1f;
  --text: "Inter", system-ui, sans-serif;
}

Try it

# scaffold, then build
rr init report
rr build report.rr.html

# your design system, inlined last so it wins
rr build report.rr.html --css brand.css

# or the bundled theme
rr build report.rr.html --theme rr

Install

# npm
npm install -g rr-cli

# Homebrew (macOS)
brew install hhushhas/tap/rr

# Scoop (Windows)
scoop install https://raw.githubusercontent.com/hhushhas/rr/main/scoop/rr.json
