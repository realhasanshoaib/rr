Composable HTML · zero dependencies

rr

A build system for composable HTML documents. Write a small .rr.html of <rr-*> tags; rr build expands them into one polished, self-contained HTML file — canonical CSS, a tree-shaken icon sprite, and both themes — that opens straight from disk with no dependencies and no network.

npm install -g rr-cli

Quickstart

Input

.rr.html a few component tags

Output

one .html self-contained

Deps

0 pure Node 
rr init report          # scaffolds report.rr.html
rr build report.rr.html # emits report.html beside it
This page is the demo. It was authored as a .rr.html file and built with rr itself — the same components documented below.

What you write vs. what you get

report.rr.html

<rr-section title="TL;DR">
  <rr-tiles>
    <rr-tile label="Shipped"
      value="3" icon="check"/>
  </rr-tiles>
  <rr-callout tone="amber">
    Open decision.
  </rr-callout>
</rr-section>

report.html

A styled section with a stat tile and an amber callout — CSS and icons inlined, nothing external.

Open decision.

The build fails loudly on unknown components, missing props, and unknown icons — a composed document is correct by construction.
