02 · Philosophy

Three commitments

Press → — this deck arrives one idea at a time. That pacing is the proposal.

Attention is the bottleneck

A slide never competes with itself. One idea per beat, set large in a narrow column; everything that isn't the current idea is either absorbed (dimmed) or not yet on stage.

Memory is made by retrieval

Reading feels like knowing — it isn't. Every chapter ends with recall cards that ask before they tell, because the check is what writes the memory.

Pace belongs to the reader

Nothing autoplays and nothing animates in. The arrow key is a metronome you hold: the pause between presses is thinking time the design deliberately protects.

03 · Typography

Soft voice, big floor

Two system faces, zero downloads. Rounded display for warmth at size; a humanist body face at a 19px floor because learning text should never be squinted at.

09 · Specimen — a real lesson in this system

What happens when you run node build.mjs doc.rr.html

Five stages. → reveals each; the previous stage dims but stays for reference.

Expand. Every <rr-*> tag is matched to its component template; props become attributes, children slot into place.

Validate. An unknown component, a missing prop, or an icon that isn't in the set fails the build loudly. That's the point — the system can't drift quietly.

Tree-shake. The icon sprite is cut down to only the symbols this document uses.

Inline. The canonical stylesheet — both themes, every token — is embedded in the head. No requests, no drift.

Emit. One polished, self-contained HTML lands beside the source. It opens from disk, today or in five years.

10 · The signature — the beam

Three states, one key

Dimming keeps context without competition: absorbed ideas stay legible for reference, the current idea owns the contrast, and the pause between key presses is where retrieval happens.

Absorbed

Dropped to muted ink — still readable, no longer loud.

Current

Full ink, full contrast. The only thing the eye is asked to hold.

Waiting

Holds its space invisibly — no layout shift when it arrives.
  • → reveals the next step before it advances the slide; ← takes steps back first.
  • State changes are contrast changes — nothing moves, nothing slides in, ≤150ms, and pure swaps under reduced motion.
  • Iris dots under the title show where you are inside the slide; the HUD shows where you are in the deck.
